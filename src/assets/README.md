# Marca TVG

- `logo-tvg.png`: imagen original provista por el usuario, conservada sin cambios.
- `app-icon-source.png`: adaptación del monograma TVG mediante ImageGen a partir del logo original, para el ícono de instalación, sobre fondo blanco.
- Exportaciones de la adaptación, con proporciones y contenido preservados: `public/icon-192.png` (192 × 192), `public/icon-512.png` (512 × 512), `public/apple-touch-icon.png` (180 × 180) y `public/favicon.png` (32 × 32). Tamaños generados mediante redimensionado determinista con ImageMagick.
- `public/manifest.webmanifest`: nombre, colores, ámbito y archivos de íconos para instalación desde el navegador.
